# 🛒 Full-Stack E-Commerce & Log Management System

A modern **Full-Stack E-Commerce Web Application** built to gain practical experience in frontend and backend development. Along with the e-commerce platform, this project also includes an additional **Log Management System** for managing and monitoring application logs.

---

## 📌 Project Overview

This project consists of three main parts:

### 🛍️ E-Commerce Frontend

The `frontend` directory contains the React-based user interface for the e-commerce application.

It includes features such as:

- 🏠 Home Page
- 🛍️ Product Browsing
- ➕ Add Product Functionality
- 🏪 Shop Section
- 🔗 Frontend-Backend Integration
- 📱 Responsive User Interface
- ⚡ Modern React-Based Interface

### ⚙️ E-Commerce Backend

The `backend` directory contains the server-side application responsible for:

- REST API development
- Product management
- Database communication
- Request handling
- Backend business logic
- Frontend-backend communication

### 📊 Log Management System

The `services` directory contains the additional **Log Management System**.

It is designed to support:

- 📝 Application logging
- 🔍 Log monitoring
- ⚠️ Error tracking
- 🕒 Activity tracking
- 📊 Log organization and management
